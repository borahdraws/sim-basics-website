# Dealing with Inlay Hints

## How to show all Inlay Hints

Open WPILib VS Code and find the folder called .vscode. Open the file called settings.json

add this line to the file somewhere:

`"java.inlayHints.parameterNames.enabled": "all"`

(need to add a comma to the previous line)

save
